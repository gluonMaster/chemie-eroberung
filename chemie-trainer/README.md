# Chemie-Eroberung

Локальный игровой тренажер по химии для ученика Klasse 8 Gymnasium Sachsen. Первая версия покрывает темы **Luft - ein Stoffgemisch** и **Wasser - eine chemische Verbindung**: немецкую химическую лексику, базовые формулы, ионы, опыты и короткие немецкие ответы.

Приложение работает как статический сайт: без npm, сборки, CDN, внешних API и серверной части.

## Запуск

Прямое открытие:

```text
chemie-trainer/index.html
```

Запуск через локальный сервер из папки `chemie-trainer`:

```bash
python -m http.server 8000
```

После этого открыть:

```text
http://localhost:8000/
```

## Режимы

- `Luft` - вопросы только по теме воздуха.
- `Wasser` - вопросы только по теме воды.
- `Gemischt` - смешанная очередь из обеих тем.
- `Fehler wiederholen` - повтор вопросов, где уже были ошибки.

На старте можно выбрать количество гексов, стартовые территории ученика, типы заданий и таймер. В строгом режиме таймера истечение времени считается ошибкой; для `short_answer` строгий таймер включается отдельным флагом.

## Учебные разделы

- Игра с абстрактной гекс-картой: правильный ответ захватывает соседний гекс, ошибка сразу теряет гекс.
- Объяснение после ошибки: правильный ответ, русский разбор, короткая немецкая формулировка и связанные Fachbegriffe.
- Словарь немецких терминов с поиском, категориями и связанными вопросами.
- Готовые немецкие ответы для подготовки к уроку или контрольной.
- Обзор прогресса, слабых вопросов и терминов для повторения.

## Локальное хранение

Данные сохраняются в `localStorage`: настройки, текущая партия и прогресс. Если `localStorage` недоступен, приложение использует память текущей вкладки и не падает. Поврежденный JSON текущей партии сбрасывается безопасно; поврежденный прогресс заменяется пустым прогрессом.

## Статус приемки v2

Встроенная проверка `ChemistryEngine.runSelfCheck(window.CHEMIE_DATA, { log: true })` проходит:

- 55 вопросов: 25 `luft`, 30 `wasser`;
- все 8 типов заданий представлены;
- `relatedTerms` и `readyAnswers.relatedQuestionIds` валидны;
- W28 имеет явные `items`;
- формулы и заряды отображаются Unicode-вариантами и принимают ASCII-ввод (`H2O`, `Na+`, `SO4^2-`).

Проверены edge cases: повтор очереди при `Luft` + 36 гексов, пустой `Fehler wiederholen`, fallback без `localStorage`, поврежденный JSON, прямое открытие `index.html`, запуск через `python -m http.server 8000`, soft/hard timer и самооценка `short_answer` с предупреждением по Fachbegriffe.
